## Español

## ⚗️ ¿Qué es MethDev?
MethDev es una plataforma centralizada para herramientas de Discord, APIs especializadas, simulaciones y narrativa interactiva.  
Un lugar donde los desarrolladores pueden **compartir, explorar y colaborar** con códigos para bots de Discord.

### 🔥 Qué ofrece 
- **Biblioteca de códigos (BDFD):** explora y publica códigos públicos, con soporte para sistemas completos.
- **Códigos complementarios:** módulos extra que se muestran junto al código principal para implementar todo el sistema.
- **API con tokens:** genera tarjetas de bienvenida y tarjetas de rango personalizadas para tu bot.
- **Límites API plan básico (gratis):** **30 solicitudes/min** y **1,000 solicitudes/día** (Pro y Empresarial suben límites).

## What is MethDev?
MethDev is a centralized platform for **Discord tools**, **specialized APIs**, **simulations**, and **interactive narrative**—a place where developers can **share, explore, and collaborate** with Discord bot code.

### What it delivers
- **BDFD Code Library** + complementary modules for full systems
- **Token-based API** (welcome cards / rank cards)
- **Free plan limits:** 30 req/min and 1,000 req/day
